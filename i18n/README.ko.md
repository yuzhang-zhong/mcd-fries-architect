# FriesCraft 🍟🗼

이 문서는 FriesCraft의 한국어 랜딩 README입니다.

## 이게 뭐야?

FriesCraft는 2026년에 유행한 “감자튀김 드래곤” 놀이에서 영감을 받은 3D 조립 게임입니다. cannon-es 물리 엔진으로 감자튀김은 팔다리/꼬리, 너겟은 몸통으로 써서 다양한 조형과 타워 챌린지를 만들 수 있습니다.
