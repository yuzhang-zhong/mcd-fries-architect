## C'est quoi ?

FriesCraft est un jeu 3D inspiré de la tendance virale « dragon de frites », avec une vraie physique (cannon-es) : les frites servent de pattes et de queue, les nuggets de corps, pour créer des formes et relever des défis de tour.

Pour le moment, la documentation complète et par défaut est maintenue en chinois :

- 中文（par défaut）: [`README.md`](../README.md)

## Jouer en local

Sans installation npm ni compilation :

```bash
git clone https://github.com/yuzhang-zhong/mcd-fries-architect.git
cd mcd-fries-architect
python -m http.server 8080
```

Ouvrez **http://localhost:8080** dans un navigateur moderne compatible WebGL.
Les bibliothèques 3D sont chargées depuis un CDN : une connexion Internet
est nécessaire. L'interface du jeu est disponible en chinois et en anglais ;
cette page est un point d'entrée documentaire, pas une traduction du jeu.
