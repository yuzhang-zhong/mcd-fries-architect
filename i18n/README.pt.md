## O que é isso?

FriesCraft é um jogo 3D inspirado na tendência viral do “dragão de batatas”, com física real (cannon-es): as batatas viram patas e cauda, e os nuggets viram corpo para montar formas criativas e torres.

## Jogar localmente

Sem instalação de npm nem etapa de compilação:

```bash
git clone https://github.com/yuzhang-zhong/mcd-fries-architect.git
cd mcd-fries-architect
python -m http.server 8080
```

Abra **http://localhost:8080** num navegador moderno com WebGL. As bibliotecas
3D são carregadas por CDN e exigem acesso à Internet. A interface do jogo
suporta chinês e inglês; esta página é uma entrada para a documentação,
não uma tradução adicional do jogo.
