## Was ist das?

FriesCraft ist ein 3D-Bauspiel, inspiriert vom viralen „Pommes-Drache“-Trend, mit echter Physik (cannon-es): Pommes werden zu Armen, Beinen und Schwanz, Nuggets zum Körper – für kreative Figuren und Turm-Challenges.

Die vollständige und standardmäßige Dokumentation ist derzeit auf Chinesisch:

## Lokal spielen

Kein npm und kein Build-Schritt:

```bash
git clone https://github.com/yuzhang-zhong/mcd-fries-architect.git
cd mcd-fries-architect
python -m http.server 8080
```

**http://localhost:8080** in einem modernen Browser mit WebGL öffnen. Die
3D-Bibliotheken werden per CDN geladen; eine Internetverbindung ist nötig.
Die Spieloberfläche unterstützt Chinesisch und Englisch. Diese Seite ist ein
Dokumentationseinstieg, keine zusätzliche Übersetzung der Spieloberfläche.
