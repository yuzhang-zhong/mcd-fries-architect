# FriesCraft 🍟🗼

Это стартовый README на русском языке для FriesCraft.

## Что это?

FriesCraft — это 3D-игра по мотивам вирусного тренда «картофельный дракон» с реальной физикой (cannon-es): картошка фри используется как лапы и хвост, наггетсы — как тело для сборки фигур и башенных испытаний.
