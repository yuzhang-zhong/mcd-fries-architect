## यह क्या है?

FriesCraft 2026 में वायरल हुए “फ्राइ ड्रैगन” ट्रेंड से प्रेरित 3D बिल्डिंग गेम है, जिसमें real physics (cannon-es) है: फ्राइज़ से हाथ-पैर/पूंछ और नगेट्स से शरीर बनाकर अलग-अलग आकृतियाँ और टॉवर चैलेंज बनाए जाते हैं।

फिलहाल, पूरा और डिफ़ॉल्ट दस्तावेज़ चीनी भाषा में रखा गया है:

- 中文（डिफ़ॉल्ट）：[`README.md`](../README.md)

## स्थानीय रूप से चलाएँ

npm इंस्टॉल या बिल्ड की ज़रूरत नहीं है:

```bash
git clone https://github.com/yuzhang-zhong/mcd-fries-architect.git
cd mcd-fries-architect
python -m http.server 8080
```

WebGL समर्थित आधुनिक ब्राउज़र में **http://localhost:8080** खोलें।
3D लाइब्रेरी CDN से आती हैं, इसलिए इंटरनेट कनेक्शन चाहिए।
गेम का इंटरफ़ेस चीनी और अंग्रेज़ी में है; यह पेज दस्तावेज़ का प्रवेश बिंदु है,
गेम इंटरफ़ेस का अतिरिक्त अनुवाद नहीं।
